# E-Commerce Sales Data Analysis Using SQL

## Project Overview

This project analyzes e-commerce order data using MySQL to understand sales performance, payment methods, product performance, and order status distribution.

## Tools Used

* MySQL
* MySQL Workbench
* SQL

## SQL Concepts

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* COUNT(), SUM(), AVG()
* HAVING
* Subqueries
* Monthly Sales Analysis
* Percentage Contribution

## Key Insights

* Credit Card payments contributed 20.86% of recorded sales.
* Online payments contributed 20.75% of recorded sales.
* Cancelled orders accounted for 20.83% of order records.
* Returned orders accounted for 20.58% of order records.

## Project Objective

To use SQL queries to analyze e-commerce data and derive useful business insights.

## Conclusion

This project helped me practice SQL queries, aggregate functions, grouping, filtering, and business data analysis.

Note: Sales figures include different order statuses unless specifically filtered in a query.
